Hi，我是 Jack Liang，一位 ABAP 开发人员。

2017 年从信息管理与信息系统专业毕业后，我一直在做 SAP ABAP 开发，到现在快 10 年了。我在两家乙方咨询公司待过，参与过不少国内 Top 500 企业的项目——从 ECC 到 S/4HANA，再到 BTP，跟着 SAP 的产品迭代一路走过来。

SAP 是服务企业发展的管理软件。这些年用下来，我慢慢理解了编程语言和企业生产之间的互动关系，开发时能更好地理解业务需求，给出更贴合实际的方案。

我主要负责开发和维护 SAP 系统的业务逻辑和数据处理模块，外围系统集成这块经验比较丰富。

## 我的个人项目：

- [DYNAMIC_DATA](https://github.com/Jack-Liang/DYNAMIC_DATA)：用于在代码中动态生成数据类型的类，支持 JSON 嵌套和预配置。
- [linktodo](https://linktodo.app/)：一个协同任务管理工具，用于在团队中管理任务和项目。
- [abap-course](https://github.com/Jack-Liang/abap-course)：一套从零开始的 ABAP 开发实战课程，24 课时以 Demo 驱动 + 代码拆解的方式带你掌握 ABAP 开发核心技能。
- [ABAP-Render-Kit](https://github.com/Jack-Liang/ABAP-Render-Kit)：一个现代 ABAP UI 框架（提取自 abapGit），让你在 SAP GUI 里用熟悉的 ABAP 模式构建富交互的 HTML 界面，内置 ECharts 图表组件。
- [sap-for-agents](https://github.com/Jack-Liang/sap-for-agents)：把 SAP NWRFC SDK 封装成长驻 HTTP 服务，通过 RESTful 接口调用任意 SAP RFC/BAPI，让 AI Agent 和其他服务无需安装 SDK、一个 JSON POST 即可访问 SAP。

## 我关注的机器学习

2018 年起，我开始持续关注机器学习和深度学习。入门时系统读过周志华的《机器学习》（西瓜书），从模型评估、决策树、神经网络一路看到支持向量机、贝叶斯和集成学习，第一次理解了机器"从数据中学规律"到底是怎么回事；后来又跟着 Goodfellow 的《深度学习》（花书）往深处走。数学底子则是边读边补的：《普林斯顿微积分读本》把微积分重新过了一遍，再跟着姜伟生的鸢尾花书系列补上线性代数和概率统计——毕竟调库谁都会，理解背后的数学才能走远。

这几年也一路见证了这个领域从学术研究走向落地：从 Transformer、BERT 到 ChatGPT 引爆的大模型时代，AI 已经从"分类一朵鸢尾花"进化到能写代码、能对话的通用助手。现在我也在尝试把它和自己熟悉的 SAP 世界连接起来——上面的 sap-for-agents 项目就是第一步，让 AI Agent 能直接调用企业系统里的能力。
